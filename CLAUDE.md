# Project Standards

- **Language:** Always use TypeScript. Strict typing, no .
- **Architecture:** Clean Architecture & SOLID principles.
- **Style:** DRY (Don't Repeat Yourself), KISS, and descriptive English names.
- **CSS:** Use CSS Variables from the theme system. No hardcoded hex/rgba.
- **Frameworks:** Keep compatibility between Ionic (Mobile) and Web (Next.js/Vue).
